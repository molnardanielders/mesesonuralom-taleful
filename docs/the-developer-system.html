The developer — the technical system

The turnkey, open-source solution: an ISO installer, control software, smart-home and the mobile/tablet app — which anyone can build on.

The ISO — turnkey, without content

A flashable disk image with everything prepared; the user adds the stories and the classification.

Lightweight Linux

With a kiosk-mode interface.

Media backend

Jellyfin/Kodi or an embedded player.

Control software

The core of the project.

Home Assistant

For the button and the room lights.

Classification database

Empty; filled from the scoring template.

Setup wizard

Children, ages, daily routine.

Hardware

Computer

Mini PC / NUC or a more powerful Raspberry Pi.

TV

The existing one, via HDMI.

Big button

Zigbee (Sonoff/IKEA), WiFi (Shelly WS1), Bluetooth (Shelly BLU), or DIY arcade + ESP32.

Optional

A microphone for voice, a smart bulb for the wind-down.

The control software — modules

Display (kiosk UI)Brain (choice + session)Classification access Store / cataloguePlayer controlHome Assistant integrationConfiguration

The classification is external data (the researcher branch's database plugs in directly); the system runs locally and offline , and the modules are swappable — a different player or a different button can be wired in.

Installation steps

Flash the ISO and boot it for the first time.

Set up children, ages and daily routine.

Pair the button (a ready-made button or DIY + ESPHome).

Load the content and the classification.
